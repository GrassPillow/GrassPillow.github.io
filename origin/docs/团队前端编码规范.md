## 1. TypeScript 规范

### 1.1 所有文件使用 TypeScript

```typescript
// 组件 — 正确
<script setup lang="ts">
// 组件 — 错误
<script setup>

// Composable — 正确
// useTheme.ts
// Composable — 错误  
// useTheme.js
```

### 1.2 类型定义规则

```typescript
// 接口定义放在 src/types/ 目录
// src/types/book.ts
export interface BookItem {
  id: number;
  title: string;
  author: string;
  description: string;
  coverColor: string;
  category: BookCategory;
}

export type BookCategory = '科幻' | '文学' | '悬疑' | '网文' | '历史' | '社科' | '技术';

// 组件中使用
import type { BookItem } from '@/types/book';

const props = defineProps<{
  book: BookItem;
  showActions?: boolean;
}>();

const emit = defineEmits<{
  (e: 'select', book: BookItem): void;
  (e: 'delete', id: number): void;
}>();
```

### 1.3 禁止事项

| 禁止 | 原因 | 替代方案 |
|------|------|----------|
| `any` 类型 | 绕过类型检查 | `unknown` + 类型守卫 |
| `as any` 断言 | 同上 | 正确的类型定义 |
| `@ts-ignore` | 掩盖类型错误 | 修复类型错误 |
| `tsconfig` 中 `"types": []` | 不加载类型定义 | 配置正确的 `types` 数组 |

## 2. Vue 组件规范

### 2.1 组件统一使用 `<script setup lang="ts">`

```vue
<script setup lang="ts">
import { ref, computed, onMounted } from 'vue';
import { useRouter } from 'vue-router';
import type { BookItem } from '@/types/book';

// --- Props ---
interface Props {
  book: BookItem;
  variant?: 'card' | 'list';
}
const props = withDefaults(defineProps<Props>(), {
  variant: 'card',
});

// --- Emits ---
const emit = defineEmits<{
  (e: 'select', book: BookItem): void;
}>();

// --- 状态 ---
const isLoading = ref(false);
const error = ref<string | null>(null);

// --- 计算属性 ---
const coverStyle = computed(() => ({
  backgroundColor: props.book.coverColor,
}));

// --- 方法 ---
const handleSelect = () => {
  emit('select', props.book);
};

// --- 生命周期 ---
onMounted(async () => {
  isLoading.value = true;
  try {
    // 异步初始化
  } catch (e) {
    error.value = (e as Error).message;
  } finally {
    isLoading.value = false;
  }
});
</script>
```

### 2.2 组件拆分原则

| 组件类型 | 最大行数 | 超过时 |
|----------|----------|--------|
| 页面视图 (views/) | 500 行 | 拆分为子组件 |
| 可复用组件 (components/) | 300 行 | 拆分职责 |
| Composable | 200 行 | 拆分逻辑 |

### 2.3 命名规范

```
组件文件:      PascalCase.vue     (BookCard.vue, EarthquakeMap.vue)
composable:   useCamelCase.ts    (useTheme.ts, useScrollAnimation.ts)
工具函数:      camelCase.ts        (parseCSV.ts, formatDate.ts)
类型定义:      PascalCase.ts       (BookItem.ts, BlogPost.ts)
样式文件:      kebab-case.css      (book-card.css, theme-toggle.css)
```

## 3. 样式规范

### 3.1 必须使用 CSS 变量

```css
/* 正确 */
.book-card {
  background: var(--color-bg-secondary);
  color: var(--color-text-primary);
  border: 1px solid var(--color-border-tertiary);
  border-radius: var(--border-radius-lg);
}

/* 错误 */
.book-card {
  background: #ffffff;
  color: #2c2c2a;
  border: 1px solid #d3d1c7;
  border-radius: 12px;
}
```

### 3.3 禁止事项

- 禁止在组件内重复声明 `font-family`
- 禁止使用 `!important`（除非覆盖第三方库样式）
- 禁止内联样式 (`style="..."`) 中的硬编码值
- 样式必须 `scoped`（除非是全局变量定义）

## 4. 状态管理规范

### 4.1 状态分类

| 状态类型 | 管理方式 | 示例 |
|----------|----------|------|
| 组件局部状态 | `ref` / `reactive` | 表单输入、展开/折叠 |
| 跨组件共享 | Pinia store | 用户信息、主题、Toast |
| 路由状态 | URL 参数 | 当前页面、筛选条件 |
| 持久化状态 | localStorage | 主题偏好、用户设置 |

### 4.2 Pinia Store 模板

```typescript
// src/stores/toast.ts
import { defineStore } from 'pinia';
import { ref } from 'vue';

interface ToastItem {
  id: number;
  message: string;
  type: 'success' | 'error' | 'warning' | 'info';
  duration: number;
}

export const useToastStore = defineStore('toast', () => {
  const toasts = ref<ToastItem[]>([]);

  const show = (
    message: string,
    type: ToastItem['type'] = 'info',
    duration = 3000
  ) => {
    const id = Date.now() + Math.random();
    toasts.value.push({ id, message, type, duration });
    if (duration > 0) {
      setTimeout(() => remove(id), duration);
    }
  };

  const remove = (id: number) => {
    toasts.value = toasts.value.filter((t) => t.id !== id);
  };

  const success = (msg: string) => show(msg, 'success');
  const error = (msg: string) => show(msg, 'error');
  const warning = (msg: string) => show(msg, 'warning');
  const info = (msg: string) => show(msg, 'info');

  return { toasts, show, remove, success, error, warning, info };
});
```

## 5. 路由规范

### 5.1 路由定义模板

```typescript
const routes: RouteRecordRaw[] = [
  {
    path: '/',
    name: 'home',
    component: () => import('@/views/HomeView.vue'),
    meta: {
      title: 'GrassPillow - 个人主页',
      requiresAuth: false,
    },
  },
  {
    path: '/blog/post/:id',
    name: 'blog-post',
    component: () => import('@/views/BlogPostView.vue'),
    props: true,  // 将路由参数作为 props 传递
    meta: {
      title: '文章详情 - GrassPillow',
    },
  },
  // 必须有 404 兜底
  {
    path: '/:pathMatch(.*)*',
    name: 'not-found',
    component: () => import('@/views/NotFoundView.vue'),
    meta: { title: '页面不存在 - GrassPillow' },
  },
];
```

### 5.2 路由守卫

```typescript
router.beforeEach((to, from, next) => {
  // 设置页面标题
  if (to.meta.title) {
    document.title = to.meta.title as string;
  }
  
  // 鉴权（如果需要）
  if (to.meta.requiresAuth) {
    const isAuthenticated = checkAuth();
    if (!isAuthenticated) {
      next({ name: 'login' });
      return;
    }
  }
  
  next();
});
```

## 6. 安全规范

### 6.1 密钥管理

```bash
# .env (不提交到 git)
VUE_APP_AMAP_KEY=your_key
VUE_APP_AMAP_SECURITY_CODE=your_code

# .env.example (提交到 git，作为模板)
VUE_APP_AMAP_KEY=
VUE_APP_AMAP_SECURITY_CODE=
```

```bash
# .gitignore 必须包含
.env
.env.local
.env.*.local
```

### 6.2 XSS 防御

```typescript
// 任何 v-html 内容必须经过净化
import DOMPurify from 'dompurify';

const sanitizedHtml = computed(() => 
  DOMPurify.sanitize(rawHtml.value, {
    ALLOWED_TAGS: ['p', 'h1', 'h2', 'h3', 'ul', 'ol', 'li', 'a', 'strong', 'em', 'code', 'pre', 'blockquote'],
    ALLOWED_ATTR: ['href', 'class'],
  })
);
```

### 6.3 禁止事项

| 禁止 | 替代方案 |
|------|----------|
| 源码中硬编码 API 密钥 | `.env` 环境变量 |
| 未经净化的 `v-html` | `DOMPurify.sanitize()` |
| 源码中硬编码绝对路径 | `@/` 别名 (`tsconfig.json` paths) |
| `eval()` / `new Function()` | 安全的 JSON.parse |

## 7. 部署规范

### 7.1 deploy.sh 安全要求

```bash
#!/bin/bash
set -euo pipefail  # 任何错误立即退出，未定义变量报错，管道失败传递

# 验证当前目录
if [ ! -f "origin/package.json" ]; then
  echo "错误: 必须在项目根目录执行"
  exit 1
fi

# 构建前检查
echo ">> 正在构建..."
cd origin
npm run build || { echo "构建失败"; exit 1; }
cd ..

# 复制产物
echo ">> 部署产物..."
cp -r origin/dist/* .
echo ">> 部署完成"
```

## 8. 代码审查清单

每次 Pull Request 必须确认:

### 安全
- [ ] 无硬编码密钥、密码、token
- [ ] 无硬编码的绝对文件路径
- [ ] `v-html` 内容经过 DOMPurify 净化
- [ ] 用户输入有验证和转义

### TypeScript
- [ ] 所有文件使用 `.ts` 扩展名
- [ ] 组件使用 `<script setup lang="ts">`
- [ ] Props/Emits 有接口类型定义
- [ ] 无 `any`、`as any`、`@ts-ignore`

### 代码质量
- [ ] 无 `console.log` 残留
- [ ] 无重复代码
- [ ] 组件不超过 500 行
- [ ] 异步操作有 loading 和 error 状态

### 样式
- [ ] 使用 CSS 变量，无硬编码颜色
- [ ] `font-family` 不在组件内重复声明
- [ ] 样式 `scoped`（全局变量除外）
- [ ] 响应式适配 (移动端/平板/桌面)

### 路由
- [ ] 新路由有 `meta.title`
- [ ] 导航入口已添加
- [ ] 有 404 兜底路由

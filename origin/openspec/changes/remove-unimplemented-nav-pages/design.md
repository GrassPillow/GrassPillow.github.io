## Context

悬浮导航（`App.vue`）是全站唯一的全局导航。当前 9 个菜单项中的 相册、待办、音乐 三个目标页内容为示例占位（picsum 图、SoundHelix 演示音源、本地示例数据），与已实现的博客/时间线等页并列，拉低站点可信度。经核查，这三个页面除悬浮菜单外无任何其他入口或内部引用，具备安全移除条件。

## Goals / Non-Goals

**Goals:**
- 悬浮菜单只保留已实现页面（9 → 6 项）
- 从源码中彻底移除 相册/待办/音乐 的路由与视图文件，不留孤立代码
- 旧 URL 自然落入 404 兜底，行为可预期

**Non-Goals:**
- 不调整其余菜单项顺序/样式，不引入分组或子菜单
- 不补入 阅读清单、时钟、地震 等缺失入口（另行决策）
- 不动其他页面的占位图内容

## Decisions

**决策 1：彻底移除（路由 + 视图文件 + 菜单项）而非仅隐藏入口**

理由：三个页面无任何真实内容与外部引用，仅隐藏会保留孤立路由与死代码；彻底移除与仓库既有"瘦身"方向一致。视图文件由 git 历史完整保留，未来需要可随时找回。

**决策 2：删除路由后旧链接由既有 404 兜底处理**

`router/index.ts` 末尾已有 `/:pathMatch(.*)*` → `NotFoundView` 路由，删除三条具体路由后访问旧 URL 会自动命中 404，无需额外改动。

**决策 3：待办页删除不迁移本地数据**

`TodoView` 的 localStorage 数据（`todo-*` 键）随页面删除自然失去展示界面；无迁移价值（示例数据）。保留键不会影响站点运行。

## Risks / Trade-offs

- [他人收藏/历史分享的 /gallery、/todo、/music 链接将失效] → 由 404 页友好提示兜底，个人站点可接受
- [误删后想恢复] → git 历史中完整保留三个视图与路由，可随时 revert
- [本地存储残留 todo 数据] → 无运行时影响，可忽略

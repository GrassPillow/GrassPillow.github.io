## Context

站点现为主题化中途状态：设计令牌已有（青绿品牌、双主题），但落地不彻底——大量视图仍硬编码白底、深灰标题、浓渐变页头、紫色等异质色块，导航球也是浓色块样式。Apple 极简的关键不是"换 logo"，而是**降低视觉噪声**：灰白底、细描边、少阴影、系统字体、大字轻标题，让内容成为主角。

## Goals / Non-Goals

**Goals:**
- 用一套"极简令牌"重新定义全局底色/文字/描边/阴影/圆角（浅色为主，深色对称）
- 页头从"渐变英雄带"过渡到"浅色留白 + 深色大字"（两种主题自适应）
- 悬浮导航、通用卡片/按钮沿用新令牌，弱化阴影与重色块
- 收敛全部视图内硬编码色值到令牌

**Non-Goals:**
- 不重构布局/组件结构、不调整路由与内容、不改菜单项
- 不引入 web 字体下载（保持系统字体零依赖）
- 不要求与 Apple 逐像素一致，只取"极简灰白 + 系统字体 + 弱投影"的范式

## Decisions

**决策 1：通过全局令牌一次性切换主视觉**

在 `App.vue` 的 `:root` / `[data-theme="dark"]` 中重定义：背景灰白阶（如 `--bg-primary:#ffffff`、`--bg-secondary:#f5f5f7`、`--bg-tertiary:#ececec`）、文字 `--text-primary:#1d1d1f`、次级 `#6e6e73`、弱化发丝边框 `rgba(0,0,0,0.08)`（深色用 rgba(255,255,255,…)）、阴影降至 `0 4px 16px rgba(0,0,0,0.06)` 量级、圆角统一 12–18px。品牌绿作为点缀保留为 `--primary-color`。

理由：现有页面已大量消费这些令牌，替换 token 即可带动全局；比逐文件改底色更一致、可回滚。

**决策 2：全局排版 + 页头文本令牌化**

- 在 `:root` 设置字体栈与 `-webkit-font-smoothing`；正文基准字号、标题字重规范放在全局样式中
- `page-title` / `page-subtitle` 从"固定白字"改为令牌色 `--page-title-color`（浅色深字/深色浅字），页头背景由视图各自的"渐变带"改为浅色（`--bg-secondary` + 微弱径向浅色晕染），大留白
- 首页 hero 同步轻量化（浅色渐变 + 深字）

**决策 3：逐个视图收敛色值（分批任务）**

对仍硬编码色值的视图做令牌替换，重点是页头区、标题区与卡片。按文件分批：全局&共享（App/nav/组件）→ 首页/关于/作品 → 博客组 → 工具组（AI/时钟/地震）→ 书籍 → 杂项校验。每批后 lint/build 保持绿。

**决策 4：悬浮导航球磨砂化**

导航球底色改为半透明白/黑（浅色 `rgba(255,255,255,.65)` + blur），描边发丝，展开菜单同质磨砂面板；hover 仅轻微缩放，焦点可见。

## Risks / Trade-offs

- [白字标题若遗漏令牌改造会出现"白底白字"] → 按"页头区先于页面内部"顺序推进，lint/目视双查
- [视图内部遗留零星硬编码色] → 批次任务明确列出文件清单，验收 grep 兜底
- [极简弱投影在暗色下过闷] → 深色令牌保留略强阴影与描边提升层次
